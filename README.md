# Line the circles（畫圈圈三角）

圈圈排成三角形（預設最底排 5 顆，共 15 顆），兩人輪流，每次在同一條直線上（橫排，或平行左、右兩條斜邊的斜線，共三個方向）畫掉 1～3 顆相連、還沒被畫掉的圈圈。**畫掉最後一顆的人輸。**

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。

- 點選圈圈，或從一顆圈圈拖到另一顆，選好後按「畫掉選取的圈圈」（或按 Enter）。
- 可調整：
  - **最底排**：3～7 顆
  - **對手**：雙人對戰，或和電腦對戰（電腦會算出最佳走法，支援到最底排 6 顆）
- 和電腦對戰時有「提示」按鈕：顯示目前是必勝還是必敗，必勝時直接幫你選好一步贏的走法（再按一次換另一種）。
- 支援悔棋、棋譜紀錄。
